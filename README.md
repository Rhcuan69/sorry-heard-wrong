The funniest one-line apology a smart speaker gives its owner after mishearing them: it heard "call Mom" as "cancel Christmas", already told the whole family, and still wishes them a Merry Christmas. Pure Python standard library, deterministic output.

## Run it

```sh
python3 main.py
```

This writes the single apology line to `$OUTPUT_DIR/entry.txt` (default `/output`).
